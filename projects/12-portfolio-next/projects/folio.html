FFolio CMS

01Overview

Folio is a hosted portfolio CMS for creators — auth, a media library, a public API, and self-serve billing in one product.

I built the first shippable version solo: multi-tenant, metered, and ready for paying users in eight weeks.

02Challenge

Multi-tenancy without leaking assets between users, and billing that never blocks a paying customer from publishing.

03Solution

Tenant-scoped everything — Postgres row-level keys for content, signed URLs for media, and a Stripe checkout with webhooks that flip plan flags in real time.
