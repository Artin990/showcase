NNord Store

01Overview

Nord is a small Nordic homeware brand that had been running on a bloated Shopify theme with a 4-second load time and a checkout that lost every third customer.

The brief: rebuild it, and make it fast enough that the team stops apologizing for it. Cut checkout drop-off in half, page under 1.5s, and let marketing ship landing pages without a deploy.

02Challenge

Legacy Shopify inventory, small team, mid-range Android customers in Northern Europe. Every rebuild attempt had died on migration.

03Solution

Next.js app with the catalog in Sanity, cart and orders in Postgres, checkout on Stripe Elements. The configurator is a 200-line state machine that persists to the server on every step change so nobody loses a build to a browser crash.

07Architecture

App Router with server components for the catalog and client islands for interactive surfaces. ISR keeps CMS-driven pages fast without a redeploy.

08Frontend

Next.js 14, Zustand for cart, design tokens in CSS variables, XState for configurator.

09Backend

Fastify API routes, Zod validators, Stripe webhooks, rate limiting on every mutation.

10Database

Postgres 16 on Neon. 7 tables. GIN indexes for search. Prisma ORM.
