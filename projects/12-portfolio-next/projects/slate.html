SSlate Docs

01Overview

Slate is a team documentation tool with a rich-text editor, real-time collaboration, and version history — Google-Docs feel, private-cloud deployment.

I led the frontend and the collaboration layer's client side, working alongside a backend engineer.

02Challenge

Real-time co-editing that never loses a keystroke — even when the connection drops mid-sentence and two people fix the same paragraph.

03Solution

Y.js CRDTs under a custom rich-text editor; every document change persists to Postgres as an update log, with snapshots every N ops for fast loads.
