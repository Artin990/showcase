# فاکتورچی — سامانه صدور فاکتور آنلاین

سامانهٔ حرفه‌ای صدور، مدیریت و چاپ فاکتور برای فروشگاه‌ها و شرکت‌ها با قابلیت اشتراک (پلن‌ها) و پنل مدیریت کامل.

> ⚠️ این نسخه برای اجرا روی **XAMPP محلی** آماده شده است.

---

## ✨ امکانات اصلی

- **صدور فاکتور** با ۵ قالب حرفه‌ای (کلاسیک، مدرن، مینیمال، شیک، شرکتی)
- **چاپ و خروجی**: چاپ مستقیم، PNG/PDF و Excel (RTL، Border، Merge، عرض ستون)
- **اشتراک‌ها و پلن‌ها**: ۵ پلن قابل مدیریت از پنل ادمین (سهمیه ماهانه، قالب‌ها، تبلیغ و…)
- **پنل مدیریت**: مدیریت کاربران، اشتراک‌ها، فاکتورها، کد تخفیف، رسیدهای پرداخت، تنظیمات سایت، نمونه فاکتورها و مدیران
- **تم روشن/تاریک** با ذخیره انتخاب کاربر + تطابق با سیستم (پیش‌فرض)
- **سامانه آبونمان ماه شمسی** برای سهمیه فاکتورها
- **لندینگ حرفه‌ای SaaS** با معرفی، پلن‌ها، نمونه‌ها و FAQ

## 🔐 امنیت

- رمز عبور با `password_hash` / `password_verify` (bcrypt)
- تمام کوئری‌ها با PDO **Prepared Statements** (ضد SQL Injection)
- **CSRF Token** روی همه فرم‌ها (فیلد `csrf_token`)
- خروجی با `e()` (ضد XSS) و `json_encode(JSON_HEX_TAG|JSON_HEX_APOS|…)`
- محافظت Brute-force بر اساس **IP + ایمیل** در جدول سرور (`login_attempts`)
- محدودسازی نرخ درخواست فراموشی رمز (ضد ایمیل‌بمب)
- هش‌شده نگه‌داشتن توکن بازیابی رمز (sha256)
- سشن امن (`HttpOnly`، `SameSite=Strict`، Regenerate پس از ورود)
- مالکیت داده‌ها: هر کاربر فقط به فاکتورهای خودش دسترسی دارد (IDOR-proof)
- کنترل نوع و اندازه فایل‌های آپلودی با `finfo` + نام تصادفی
- سیاست رمز عبور: حداقل ۸ کاراکتر، شامل حرف و عدد
- آپلودها از پوشه‌protected خارج هستند و به‌صورت مستقیم سرو نمی‌شوند

## 🚀 نصب روی XAMPP

1. پروژه را در `C:\xampp\htdocs\invoice-app` قرار دهید
2. XAMPP را اجرا و **Apache** و **MySQL** را روشن کنید
3. دیتابیس `invoice_app` را بسازید:
   ```sql
   CREATE DATABASE invoice_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
4. فایل `database/invoice_app_final.sql` را در دیتابیس **invoice_app** ایمپورت کنید
   (یک دکمه «Import» در phpMyAdmin همین فایل را انتخاب کنید یا خط فرمان زیر را بزنید):
   ```
   mysql -uroot invoice_app < database/invoice_app_final.sql
   ```
5. سایت را باز کنید: http://localhost/invoice-app/

> ⚠️ کاربر/ادمین اولیه در SQL نهایی برای ورود اولیه ساخته شده است. پس از اولین ورود، **رمز عبور را از پنل مدیریت تغییر دهید** و برای ادمین «مدیران» حساب جدید بسازید.

## 🗂 ساختار

```
invoice-app/
├── index.php               روتینگ (URL‌ها: /dashboard, /invoices, /admin, …)
├── assets/                 CSS و JS
├── app/
│   ├── config/config.php   تنظیمات (دیتابیس، APP_URL، APP_DEBUG و…)
│   ├── core/               هسته (Router, Auth, Controller, Database, helpers)
│   ├── controllers/        کنترلرهای کاربر
│   │   └── admin/          کنترلرهای پنل مدیریت
│   ├── models/             مدل‌ها (کاربر، فاکتور، اشتراک، پلن، تخفیف…)
│   └── views/              قالب‌ها (layouts، landing، dashboard، invoices، auth، admin)
├── uploads/                فایل‌های آپلودی (رسید پرداخت)
└── database/               فایل SQL نهایی
```

## 🎨 تم و قالب‌ها

- سیستم رنگ با **CSS Variables** روی همه اجزا (لندینگ، داشبورد، ادمین، فرم‌ها، فاکتورها)
- سوییچ دستی ماه/خورشید در هدر، داشبورد و پنل ادمین؛ ذخیره در `localStorage`
- حالت خودکار از سیستم عامل وقتی کاربر انتخابی نکرده باشد
- ۵ قالب فاکتور با رنگ‌بندی و ساختار متفاوت، انتخابی هنگام ساخت

## 🌍 محیط تولید (cPanel)

- در `app/config/config.php` مقادیر دیتابیس cPanel را وارد کنید
- `APP_DEBUG` به‌صورت خودکار برای بازدیدکنندگان غیرمحلی `false` می‌شود
- HTTPS را فعال کنید (بک‌اند `secure` شدن کوکی سشن از همین طریق انجام می‌شود)
- برای ایمیل بازیابی رمز، یک صندوق پستی روی دامنه بسازید (SPF/DKIM)
